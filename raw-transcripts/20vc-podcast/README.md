- `guests.json` — single flat array of episode metadata (guest / company / one_liner / category / video_id / title). Use this as the primary index when looking up "who said what".

## How to query this data

Best entry points depending on what you want:

1. **Looking up a specific person** → grep `guests.json` for their name, get `video_id`, then read `transcripts/{video_id}.txt` or `summaries/{video_id}.json`.
2. **Topic-based search** → use `index.json`'s `topics` and `key_insights` fields.
3. **Reading raw transcripts** → `transcripts/*.txt` (each ~30-60 min episode, plain text, no timestamps).
4. **Quick browsing by category** → use sections above.
