# Donating Agent Skills to the Agentic AI Foundation

# Source: Anthropic News

## Summary

Anthropic is donating Agent Skills — an open standard for giving AI agents specialized knowledge and workflows — to the Agentic AI Foundation (AAIF), which is hosted under the Linux Foundation. More than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, have integrated the standard since it was published in December 2025.

## Key Details

**What a skill is:** A folder with a SKILL.md file, plus any scripts or reference material an agent needs for a task.

**Adoption:** About 1 million skills have been published and nearly 280 million installed.

**What's donated:** The name, logo, GitHub organization, and agentskills.io domain. People can use or contribute to the standard without joining the AAIF.

**Maintainers:** Engineers from Anthropic, Google, OpenAI, and other companies maintain it as individuals. David Soria Parra and Mahesh Murag are Lead Maintainers.

**Next steps:** A proposed roadmap covers versioned releases, a formal proposal process, and security guidance for skill authors and installers. Feedback is collected on Discord.

**Context:** Anthropic co-founded the AAIF with Block and OpenAI last year and previously donated the Model Context Protocol (MCP) to it.
