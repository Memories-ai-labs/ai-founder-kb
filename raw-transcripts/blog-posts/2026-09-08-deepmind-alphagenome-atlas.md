# AlphaGenome Atlas: A predictive map of every possible DNA letter change in the human genome
# URL: https://deepmind.google/blog/alphagenome-atlas-a-predictive-map-of-every-possible-dna-letter-change-in-the-human-genome/
# Date: 2026-09-08
# Source: Google DeepMind Blog

## Summary

AlphaGenome Atlas is a comprehensive genomic database developed by Google DeepMind containing "predictions for the effects of 9 billion single-nucleotide variants — every single-letter change possible — in the human genome."

## Scale

- 1-petabyte dataset
- 9 billion single-nucleotide variant predictions
- Thousands of cellular contexts and tissues (human and mouse)

## Core Features

- Molecular effect predictions for gene regulation across multiple cell types
- The Variant Impact (AVI) score — a single number describing the impact of each genetic variant
- Feature attributions linking scores to specific biological mechanisms
- Over 2,500 identified DNA sequence motifs

## Applications

- Identifying rare disease variants
- Mapping genetic associations with complex traits
- Understanding regulatory DNA sequences (non-coding genome where most disease-associated variants reside)

## Access

Available free for academic research via:
- Web portal
- API access
- Integration with Google Antigravity's agentic platform

## Relevance for AI Founders

AlphaGenome Atlas signals DeepMind's continued push into scientific AI infrastructure. The combination of petabyte-scale precomputed predictions + API access + agentic platform integration represents the "foundation model + inference API" playbook applied to genomics. AI founders in biotech/healthtech should note this as the model for how scientific AI infrastructure will be commoditized — free academic access to capture researchers, then monetize enterprise/pharma via API and platform.
