# Introducing Claude Sonnet 5
# Publisher: Anthropic
# URL: https://www.anthropic.com/news/claude-sonnet-5
# Date: 2026-06-30
# Source: Anthropic News

## Overview

Anthropic launched Claude Sonnet 5, described as "the most agentic Sonnet model yet." The model can make plans, use tools like browsers and terminals, and operate autonomously at capabilities that previously required larger, more expensive models.

## Performance

Sonnet 5 demonstrates substantial gains over Sonnet 4.6, particularly in reasoning, tool use, coding, and knowledge work. Performance approaches Opus 4.8 while maintaining lower costs. The model shows meaningful improvements across agentic search and computer use evaluations.

## Availability and Pricing

Available across all Claude plans immediately:
- **Introductory pricing** (through August 31, 2026): $2 per million input tokens / $10 per million output tokens
- **Standard pricing** (after August 31, 2026): $3 per million input tokens / $15 per million output tokens

Default model for Free and Pro plans. API identifier: `claude-sonnet-5`

## Safety Evaluations

Pre-deployment assessments showed Sonnet 5 improved upon Sonnet 4.6:
- Better refusal of malicious requests
- Lower hallucination rates
- Substantially reduced capability for cybersecurity exploitation vs. Opus models
- Real-time cyber safeguards enabled by default

## Significance for Builders

Sonnet 5 narrows the cost-performance gap between mid-tier and frontier models. For AI founders: tasks that previously required Opus 4.8 (and its higher cost) may now be achievable with Sonnet 5, improving unit economics for agentic products.
