# Granite Switch 4.1.1 — Update models like you update software
# URL: https://huggingface.co/blog/ibm-granite/granite-switch-4-1-1
# Date: 2026-10-29
# Source: Hugging Face Blog

IBM Granite Switch 4.1.1 is a patch release — fully backwards compatible with Granite Switch 4.1, no migration needed.

**Two updates:**
1. **Granite Speech ASR model:** A multilingual speech-to-text model covering 10 languages, with built-in punctuation and capitalization.
2. **Decision adapter:** An updated adapter in granitelib-core with better performance on the Jev Decision Index test set.

The base model was not changed. IBM plans to release tutorials and an Adapter SDK so developers and third-party providers can build, version, and update their own adapters.
