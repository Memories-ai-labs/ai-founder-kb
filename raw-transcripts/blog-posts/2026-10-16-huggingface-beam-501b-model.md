# Welcome Beam: a 501B open model you can own, customize, and scale
# URL: https://huggingface.co/blog/reflection-beam
# Date: 2026-10-16
# Source: Hugging Face Blog

**Authors:** ben burtenshaw, merve, Pedro Cuenca
**Publisher:** Hugging Face / Reflection (US lab)

Beam is a 501B-parameter mixture-of-experts model from US lab Reflection, with 23B parameters active per token, a 1M-token context window, and an Apache 2.0 license. It targets coding and agentic work for teams that want frontier-scale capability on their own hardware or cloud and want to customize it.

**Key specs:**
- 501B total parameters, 23B active per token (MoE)
- 1M token context window
- Apache 2.0 license (fully open)
- Available checkpoints: BF16, FP8, NVFP4
- Day-0 support in: transformers, vLLM, SGLang
- SFT and GRPO training recipes included

**Significance:** One of the largest fully open-weight models released to date, matching or exceeding frontier closed model capabilities while being fully licensable for commercial use. $10,000 Hub credit prize announced for projects built with Beam.
