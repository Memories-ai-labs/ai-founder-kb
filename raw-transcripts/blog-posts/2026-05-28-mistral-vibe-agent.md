# Vibe Gets to Work — Mistral AI Agent Launch
# URL: https://mistral.ai/news/vibe-agent
# Date: 2026-05-28
# source: Mistral AI News

## Overview

Mistral rebranded Le Chat as Vibe, positioning it as "one agent for long-running, multi-step work." The unified platform handles both professional tasks and coding assignments across web, mobile, and IDE environments.

## Work Mode Features

Vibe's Work Mode operates across multiple business systems including Google Workspace, Outlook, SharePoint, and Slack. It manages "enterprise knowledge search," structured data analysis with visualizations, and document synthesis through a Canvas tool. The agent can schedule recurring tasks on daily, weekly, or monthly cadences and extend functionality through custom skills.

## Code Mode Capabilities

Code Mode runs in isolated sandboxes and handles features, bug fixes, refactoring, and pull request generation. Sessions persist across device shutdowns and integrate with GitHub, GitLab, Jira, and Linear. The new VS Code extension "works across your whole project in a side panel" while the CLI receives updates including editable planning, session teleportation, and scoped permissions.

## Pricing & Availability

- Free: Basic tasks
- Pro: $14.99/month
- Team: $24.99/user/month
- Enterprise: Custom deployments

Access points: chat.mistral.ai, code.mistral.ai, VS Code marketplace, and CLI.

## Competitive Context

Mistral's rebrand follows the broader market shift toward long-running agentic tasks. Vibe competes directly with Claude Code (Anthropic), GitHub Copilot (Microsoft), and Cursor for developer workflows, and with Notion AI / Microsoft 365 Copilot for enterprise knowledge work.
