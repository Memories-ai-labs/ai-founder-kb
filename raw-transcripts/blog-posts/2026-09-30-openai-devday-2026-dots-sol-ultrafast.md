## Major Product Launches

### Dots (Always-On Agents)
OpenAI unveiled "dots"—autonomous agents powered by GPT-6 Astra that run on dedicated cloud infrastructure. These agents connect to "4,000+ apps and Slack/Teams" and allow users to set boundaries for autonomous actions versus actions requiring approval. Early testers reported proactive behavior, including one agent that negotiated cost reductions with customer service.

### GPT-6.1 Sol
Positioned as "near-Astra intelligence for a fifth of the price," Sol offers significant cost advantages with cached input at "$0.10 (a 95% cache discount)." The model reportedly ties Astra on DeepSWE benchmarks and beats Opus 5.5 on AutomationBench at substantially lower costs.

### Ultrafast Mode
This feature delivers up to "8x faster generation (300 tok/s) in Codex" with corresponding speed improvements in the API, though at 6x standard pricing.

### Decisions API & Platform Updates
New tools include a classification API for rapid routing decisions and expanded Codex functionality with persistent cloud environments. The rollout also featured plan restructuring.

## Scale & Business Metrics
- ChatGPT reached 1.2 billion weekly active users
- OpenAI annual recurring revenue approaches $70 billion

## Significance for AI Founders

This DevDay represents OpenAI consolidating its platform strategy:
1. **Always-on agents** (Dots) signal the shift from chatbots to ambient AI services
2. **Cost-tiered models** (Sol at 1/5th of Astra pricing) suggest a mature model portfolio strategy
3. **Decisions API** enables rapid classification/routing — key infrastructure for agentic workflows
4. **Agents API** formalizes the multi-agent orchestration layer

The 1.2B WAU figure and ~$70B ARR metrics confirm OpenAI's position as a consumer and enterprise platform at unprecedented scale.
