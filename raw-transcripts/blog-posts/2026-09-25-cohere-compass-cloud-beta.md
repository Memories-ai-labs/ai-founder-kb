# Compass is coming to the cloud
# URL: https://cohere.com/blog/compass-cloud-beta
# Date: 2026-09-25
# source: Cohere Blog

## Overview

Cohere announces Compass — its enterprise retrieval platform — entering private beta as a managed cloud service (Compass Cloud).

## Three Key Problems Addressed

### 1. Token Economics
More precise retrieval reduces irrelevant results passed to AI models, lowering inference costs and context usage.

### 2. Agentic Access Patterns
Agents need reliable retrieval across multiple sequential queries, not just single searches.

### 3. Fragmented Stacks
Production systems often combine separate tools for ingestion, indexing, and reranking — creating integration complexity.

## Platform Components
- Document parsing
- Embedding
- Hybrid search
- Reranking
- Access control

All in one integrated service.

## Performance

14-16 point improvement on Azure Search (from 64.8 to 81.1) on a financial industry benchmark.

## Integration

- Compass API for custom RAG applications
- MCP server for agentic retrieval

## Significance for AI Founders

Enterprise RAG infrastructure is consolidating. Point solutions (separate vector DBs, rerankers, parsers) are being replaced by integrated platforms. Founders building on top of retrieval infrastructure should plan for this consolidation to affect their stack choices.
