# Bringing More Control Over Your Connectors
# URL: https://mistral.ai/news/more-control-over-connectors/
# Date: 2026-06-24
# Source: Mistral AI News

Mistral AI announced several new connector capabilities designed to enhance security and control for enterprise integration.

## Key Features Announced

**Enriched admin controls**: Enable organizations to manage connector access at workspace and organization levels, allowing administrators to "turn individual tools on or off for a whole org or one workspace."

**New authentication options**: API keys with connector scopes to prevent impersonation in automated workflows, and multi-account connector support allowing users to authenticate with multiple accounts to a single connector.

**Connectors Debugger**: Provides step-by-step root cause analysis for MCP connectors.

**Vibe Code and Workflows integration**: Connectors are now integrated into both environments, enabling broader use of governed integrations across development and automation contexts.

## Supported Integrations

The platform now covers more than 60 integrations across categories including knowledge management, communication, work operations, payments, analytics, and developer platforms—supporting services like Salesforce, HubSpot, GitHub, Slack, and Notion.

## Availability

Enterprise controls, credentials management, and Vibe Code integration are generally available; Connectors Playground and Workflows integration are in public preview.
