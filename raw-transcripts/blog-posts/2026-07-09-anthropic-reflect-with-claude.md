# Introducing a way to reflect on how you use Claude

**Publisher:** Anthropic
**Date:** 2026-07-09
**URL:** https://www.anthropic.com/news/reflect-with-claude
**Category:** Product Announcement

---

## Overview

Anthropic launched a beta feature enabling users to review and understand their Claude usage patterns. The tool addresses a common user concern: determining how AI can best integrate into daily workflows and when human effort remains preferable.

## Key Features

### Usage Tracking and Visualization
The reflection dashboard summarizes Claude activity across customizable timeframes (1, 3, 6, or 12 months), displaying key topics, usage patterns, and task types. Users can examine when they use Claude most and what activities consume their time.

### Reflective Prompts
The feature surfaces periodic questions like "What's one thing you want to keep doing yourself, even if Claude could do it faster?" to encourage intentional AI integration.

### Controls and Preferences
Users can set quiet hours or schedule break reminders after specified usage durations.

## AI Fluency Framework Integration

The reflection tool aligns with Anthropic's 4D AI Fluency Framework:
- **Delegation:** Goal-setting and AI engagement decisions
- **Description:** Crafting effective prompts
- **Discernment:** Evaluating AI output quality
- **Diligence:** Responsible AI use practices

## Privacy Protections

- Excludes incognito chats
- Excludes underlying files from connected tools
- Health-related conversations excluded
- Sensitive discussions appear only as high-level summaries

## Availability

Currently in beta for Free, Pro, and Max users with Memory enabled. Accessed through Claude's Settings.
