# Introducing Gemini 3.8 Live with Live Avatar
# URL: https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-with-live-avatar/
# Date: 2026-09-24
# Source: Google DeepMind Blog
# Authors: Shuo-yiin Chang (Research Scientist), CJ Zheng (Software Engineer), Gemini Audio Team

## Summary

Google introduces visual presence capabilities to Gemini's conversational AI through "near real-time visual presence" paired with speech technology — photorealistic AI avatars with precise lip-syncing and natural expressions.

## Key Points

**Core Feature**
Live Avatar adds near real-time visual presence to Gemini's conversational AI, with precise lip-syncing, natural expressions, and fluid turn-taking for interactive enterprise applications.

**Multimodal Processing**
Processes visual and audio inputs simultaneously; uses asynchronous tool execution so the avatar can fetch data and trigger tools while maintaining uninterrupted dialogue.

**Multilingual Support**
Native speech-to-speech synchronization across 97 languages with adaptive lip-sync that doesn't degrade video quality.

**Customization**
Organizations can generate custom avatars from reference images while maintaining brand identity.

**Safety**
All outputs include SynthID watermarking to ensure AI-generated content remains detectable.

**Availability**
Launched in Gemini Enterprise with API access for developers.
