# Scaling Indic Pretraining: 2.8 Trillion Tokens and an Open Data Generation Pipeline

*Published October 16, 2026 on Hugging Face Blog (NVIDIA)*

## Summary

NVIDIA shares research on scaling pretraining data for Indic (South Asian) languages, introducing a 2.8 trillion token dataset and open-source data generation pipeline.

## Key Points

- 2.8 trillion token dataset covering Indic languages
- Open data generation pipeline released for community use
- Addresses underrepresentation of Indic languages in LLM pretraining
- Part of broader push for multilingual and non-English language AI capability

## Significance

- Multilingual AI capability is increasingly important as AI adoption grows in India and Southeast Asia
- Open pipeline enables community to build on and extend the dataset
- Largest publicly documented Indic language pretraining effort to date
