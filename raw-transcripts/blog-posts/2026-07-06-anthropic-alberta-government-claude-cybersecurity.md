# Government of Alberta Uses Claude to Find and Fix Cybersecurity Vulnerabilities
# Publisher: Anthropic
# URL: https://www.anthropic.com/news/alberta-government-claude-cybersecurity
# Date: 2026-07-06
# source: Anthropic News

## Overview

Alberta's Ministry of Technology and Innovation deployed Claude Code with Opus and Sonnet models to identify and remediate security vulnerabilities across provincial government systems since 2025.

## Key Accomplishments

**Massive Code Review:** ~50 autonomous agents scanned 466 million lines of government code in 20 hours — a task estimated to require 6.5 years using traditional methods. Two-stage process: flagged known vulnerability patterns, then provided exact file and line citations for developer verification.

**Vulnerability Remediation:** Claude Code generated fixes, created automated tests where needed, and modernized outdated systems. One legacy Java subsidy portal originally requiring five months to build was rebuilt in four to five days.

**Continuous Security Monitoring:** Specialized review agents now continuously assess applications throughout development, including "red team" agents simulating attacks and "blue team" agents evaluating defenses against international security standards.

## Scale and Context

The Ministry manages systems for 27 provincial ministries: ~1,280 applications, 3,400 code repositories. Most systems had never undergone systematic security reviews; technical debt accumulated in the billions of dollars.

## Future Plans

Alberta intends to consolidate 185 legacy applications from one ministry into 16 modern applications using Claude Code, while expanding the approach across provincial government through an upcoming scaling program.
