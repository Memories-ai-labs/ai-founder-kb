# Introducing Claude Opus 5.5
# URL: https://www.anthropic.com/claude-opus-5-5
# Date: 2026-09-22
# Source: Anthropic

---

Anthropic introduced Claude Opus 5.5 on September 22, 2026. The model performs comparably to Claude Fable 5.1 while costing 40% less than Opus 5. It underwent external evaluation by Frontier Design and METR before release.

## Performance Highlights

**Coding Capabilities:**
Opus 5.5 excels at large-scale migrations and refactoring work. One early tester "completed a 680,000-line code migration in less than a day" using the model, contrasting sharply with traditional team timelines. On web performance optimization, it "succeeded 39 of 40 times" versus smaller improvements from Opus 5.

**Knowledge Work:**
The model demonstrates strong research abilities. In financial analysis testing, it "largely solved" evaluation suites for investment firms while "detecting errors in evaluation instructions."

**Agentic Coding Benchmarks:**
- Terminal-Bench 4.0: 66.4%
- FrontierCode v1.1: 54.4%
- CursorBench 4.0: 57.8%

## Pricing Structure

- Input tokens: $4 per million (20% reduction from prior)
- Output tokens: $20 per million (20% reduction)
- Cache reads: $0.20 per million (60% reduction)

## Safety Features

Opus 5.5 achieved "the best scores of any model to date" on Anthropic's behavioral audit. It demonstrates improved resistance to prompt injection and reduced likelihood of taking irreversible actions outside defined boundaries.

The model launches with safeguards comparable to Fable 5.1 for cybersecurity and biology research, requiring verification programs for certain use cases.

## Communication Improvements

Testers reported that the model "writes the way I do," with clearer structure and better readability. Responses prioritize important information upfront while avoiding jargon-heavy explanations.

## Availability

Accessible across AWS, Google Cloud, and Microsoft Azure platforms.
