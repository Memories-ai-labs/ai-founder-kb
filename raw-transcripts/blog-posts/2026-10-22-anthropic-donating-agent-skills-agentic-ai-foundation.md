# Donating Agent Skills to the Agentic AI Foundation
# URL: https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation
# Date: 2026-10-22
# Source: Anthropic News

Anthropic is donating Agent Skills, an open standard for giving AI agents specialized knowledge and workflows, to the Agentic AI Foundation (AAIF) under the Linux Foundation.

A skill is a folder with a SKILL.md file plus any supporting scripts or reference material. Anthropic developed skills for Claude Code to add procedural knowledge for business tasks. Over 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, have integrated the standard since December 2025. About 1 million skills have been published, and nearly 280 million installed.

Anthropic is transferring the name, logo, GitHub organization, and agentskills.io domain. Engineers from Anthropic, Google, OpenAI, and other companies will maintain it as individuals. David Soria Parra and Mahesh Murag are Lead Maintainers.

The proposed roadmap covers versioned releases, a formal proposal process, and security guidance for writing and installing skills. Feedback is invited through the project's Discord.

The full specification is at agentskills.io.
