# Pay for Hugging Face Hub with your Google Cloud Account
# URL: https://huggingface.co/blog/hub-gcp-marketplace
# Date: 2026-11-10
# Source: Hugging Face Blog

---

Hugging Face now allows organization admins to link a Hugging Face organization to a Google Cloud account via Google Cloud Marketplace. Once linked, Hugging Face usage is billed to the Google Cloud invoice.

## Covered Services

- Team or Enterprise subscriptions
- Pay-as-you-go compute: Jobs, Inference Endpoints, Inference Providers, GPU Spaces, ZeroGPU quota extension
- Additional storage
- All at standard Hugging Face public pricing

## Setup Steps

1. Subscribe to Hugging Face Hub listing on Google Cloud Marketplace (choose project + billing account)
2. Sign in to Hugging Face and select organization to link (must be admin)
3. Hugging Face reviews subscription; during review, usage stays on existing payment method

## Notes

- Organizations with existing credit card: switches at start of next billing period
- Free-tier organizations with no card: usually switch immediately
- Google Cloud billing replaces credit card (Hugging Face credits not addable while using GCP billing)
- Usage trackable in both HF organization billing settings and Google Cloud Billing reports
- Support: billing@huggingface.co
