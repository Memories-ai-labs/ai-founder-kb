## Summary

Chimala presents a three-stage framework for leveraging AI agents to create distinctive designs rather than generic outputs. The core insight is that LLMs naturally default to predictable, safe choices due to their training as next-token predictors.

## The Three-Stage Framework

**Discover phase:** Using seed strings and ambitious prompts to explore varied design directions. Feed random strings as inspiration sources to break AI's tendency toward committee-pleasing defaults.

**Define phase:** Employing design critic subagents, image generation, and video tools to develop individual design identity. Create feedback loops between coding and critic agents.

**Deliver phase:** Removing unnecessary elements and eliminating "AI tells" — signals that a design was AI-generated rather than intentionally crafted.

## Key Techniques

- Feed random strings as inspiration sources to avoid code-based design clichés
- Create feedback loops between coding and critic agents
- Incorporate visual media generation alongside code generation
- Human judgment required to steer outputs toward distinctive rather than safe results

## Core Insight for Founders

LLMs default to predictable, safe outputs because of how they are trained. Getting distinctive design from AI requires intentional steering — not just prompting, but building multi-agent loops that push past the mean.
