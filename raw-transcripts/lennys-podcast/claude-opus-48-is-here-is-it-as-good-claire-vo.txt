## Episode Summary

Host Claire Vo reviews Claude Opus 4.8 across three domains: coding, creative tasks (children's games), and business strategy.

**Strengths:**
- Excels at greenfield prototypes, one-shot features, and fast execution
- Improved judgment and honesty — flags uncertainties, avoids unsupported claims, roughly 4x less likely to let code flaws pass without comment vs Opus 4.7
- Better at asking clarifying questions and pushing back on unsound plans before implementation
- Works independently for extended periods

**Weaknesses:**
- Struggles with "the last 10%" — edge cases in existing codebases
- Still underperforms Opus 4.7 on data-heavy strategy and roadmap work
- Hallucination issues persist

**Key new features in this release:**
- Dynamic Workflows: Claude Code now supports hundreds of parallel subagents in a single session, enabling large-scale codebase migrations
- Effort Control: users can select how much computational effort Claude applies (higher = better results, higher token cost)
- Messages API Enhancement: developers can update system instructions mid-task without disrupting prompt caching

**Pricing:** Maintains Opus 4.7 pricing ($5/M input, $25/M output; Fast mode $10/$50). Available via claude.ai and API as `claude-opus-4-8`.
