## Episode Summary

30-minute episode exploring OpenAI Codex's `/goal` command — how it transforms AI from an interactive assistant into an autonomous multi-hour agent.

**What Goals Are:**
The `/goal` command enables AI to work autonomously on complex, multi-step tasks rather than requiring turn-based interactions with continuous user direction. Unlike prompts, Goals run loops with verification steps.

**Real-World Applications demonstrated:**
- Eliminating hundreds of error logs through a 5-hour autonomous coding run
- Cleaning 3,900 emails down to 68 in under 4 hours
- Organizing hundreds of Linear project management tasks

**Framework for Effective Goals (6 components):**
1. Measurable outcomes
2. Verification methods
3. Clear constraints
4. Context about the codebase/environment
5. Definition of "done"
6. Fallback behavior

**Key Distinction:**
"The difference between prompts and Goal-based loops" — Goals represent managing AI at a strategic level rather than constant supervision.

**Tools Referenced:** Codex, Sentry, Vercel, Linear
