## Summary

Claire Vo explains that "It's not the model, it's the harness" — a concept many discuss but few define clearly. She demonstrates by constructing a practical tool for automating Sentry bug diagnosis at ChatPRD using the Claude Agent SDK.

## What the episode covers

Six key areas:

1. **Harness definition** — A specialized system built around AI agents for specific workflows
2. **When to build vs. use existing tools** — Understanding when custom solutions beat general-purpose alternatives like Claude Code
3. **Permission encoding** — Structuring which actions an agent can perform
4. **Core components** — The three essential building blocks every harness requires
5. **Model selection** — How both GPT-5.5 and Claude Opus contributed to building the harness itself
6. **Output structuring** — Designing artifacts so teams can utilize results effectively

## Technical implementation

The custom harness integrates with Sentry, Linear, GitHub, and Vercel using the Claude Agent SDK. It features a terminal interface built with the Ink library and operates on runs, tasks, tools, and artifacts architecture.

Claire eliminated repetitive prompting by encoding "dear agent, please fix this bug" workflows directly into automated processes handling evidence gathering and root-cause analysis.
