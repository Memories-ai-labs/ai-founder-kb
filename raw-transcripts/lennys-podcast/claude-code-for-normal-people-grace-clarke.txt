## Guest Background

Grace Clarke is an AI educator who taught herself Claude Code and built a curriculum around the process. She now operates her entire service business using Claude-built tools and teaches others to do the same.

## Key Topics Covered

### Business Automation
- Built a pipeline operator that "moves clients through your process automatically" on an hourly basis
- Created a proposal system using password-protected, interactive HTML documents instead of traditional proposals
- Developed a custom Gmail replacement in under 30 minutes using Cowork

### AI Skill Development
- Introduced concept of "voice guide" skill files to ensure Claude outputs maintain her distinctive voice
- Teaches "intent engineering" rather than prompt engineering
- Implements forcing functions to help non-technical users build habits with AI

### Personal Use Cases
- Uses Claude on mobile for workout tracking, plant photo management, and daily tasks
- Integrated AI into everyday workflows alongside professional work

## Main Learning Points

1. **Building muscle memory** for AI tool usage is essential for adoption
2. **Skill files** contain voice guides, proposal rules, and version management
3. **The biggest barrier to adoption** is overcoming misconceptions about AI capability
4. **Non-technical users** can build sophisticated business tools with Claude Code; coding background not required
5. **Intent engineering** (communicating what you want to achieve) beats traditional prompt engineering

## Tools Referenced

Claude, Claude Code, Netlify, Google Forms, Google Sheets, Google Cloud services

## Significance

Demonstrates that Claude Code adoption extends beyond engineers — service business owners using it for CRM, proposals, client workflows. Grace's "voice guide" skill file concept is a practical pattern for maintaining consistent AI output quality.
