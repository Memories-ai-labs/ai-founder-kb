## Episode Overview

Alessio Fanelli demonstrates his personal setup for managing autonomous coding agents using OpenAI Symphony and Linear, running the entire workflow from his phone. The episode features live demos of both the Symphony/Linear agent management setup and a Codex-powered Pokémon card-scouting workflow.

## Key Topics and Insights

**Mental Model Shift: From "Agent Prompter" to "Agent Manager"**
- The proper frame for working with autonomous coding systems is management, not prompting
- Agent managers define tasks, monitor progress, and resolve blockers — not write prompts

**Symphony + Linear Integration**
- Linear serves as the state machine tracking task state
- OpenAI Symphony orchestrates agents through the development lifecycle
- The combination enables asynchronous, phone-based agent supervision without manual intervention at each step

**Infrastructure Scaling**
- Local Mac Minis are insufficient for agent-scale workloads
- Cloud VPS provides necessary scalability and persistent availability
- Cost tracking: ~221 million tokens processed across workflows

**Token Economics**
- Track cost per task as the primary unit of agent efficiency
- Alessio's setup runs Codex autonomously to hunt underpriced Pokémon cards on eBay
- PSA grading data extraction + market pricing → profitable deals in the $10K–$20K card range
- This operates as an actual business: Merlin Games, a card shop in San Carlos

**Prompt Optimization Insight**
- Counterintuitive recommendation: drastically REDUCE instruction files, not expand them
- Shorter, cleaner system prompts often produce more reliable agent behavior

**Glimpse for Agent Perception**
- Tool for enhancing agent sensory input — agents "see" more of the relevant context
- Enables better decision-making in complex codebases

**Business Model Innovation**
- AI enables entirely new categories of small businesses
- The card-scouting workflow illustrates how autonomous AI can power arbitrage-based microenterprises
- Fanelli runs this in parallel with Kernel Labs (developer tools) and Latent Space (podcast)
