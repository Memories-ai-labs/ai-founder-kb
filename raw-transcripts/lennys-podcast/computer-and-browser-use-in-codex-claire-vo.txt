## Overview

This episode showcases practical applications of browser and computer use capabilities through Codex (ChatGPT's desktop app). Claire demonstrates how she leverages these AI features for QA testing, personal productivity, and everyday tasks.

## Key Use Cases Demonstrated

1. **QA testing an onboarding flow** — Codex discovers 11 issues including one high-severity blocker without manual testing steps.
2. **Persona-based testing** — Using husband EJ Lawless's technique: testing with specific personas to uncover friction points that generic testing misses.
3. **LinkedIn inbox management** — AI handles inbox triage without manual intervention.
4. **AI-powered shopping** — Browsing Free People's sale, adding items to cart autonomously.
5. **Rapid-fire applications** — Form filling, iPhone mirroring control, router management, Google Docs creation.

## Core Insight

"Under-prompting frontier models gets better results than detailed step-by-step instructions" — providing minimal guidance encourages the AI to work harder and think independently rather than following narrow prescribed steps.
