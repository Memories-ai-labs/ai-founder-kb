## Episode Overview

Host: Claire Vo. Felix Rieseberg, engineering lead for Claude Cowork and Claude Code Desktop, demonstrates practical applications of Claude for solving everyday problems. Three live demonstrations.

## Key Discussion Points

### 1. Converting 2D Floor Plans to 3D Interactive Walkthroughs
Felix shows how Claude Cowork transforms floor plan images into navigable 3D environments where users can dynamically move furniture.

### 2. The "Abstraction Layer Up" Philosophy
Rather than manually entering data, let Claude extract information automatically—e.g., using email receipts as an inventory database for furniture and purchases. This applies to clothing, medical records, and travel history—"existing structured databases waiting to be unlocked."

### 3. Model Selection Strategy
- Use **Sonnet** for well-defined problems
- Choose **Opus** when Claude needs to interpret actual intent vs. literal requests
- Decision hinges on problem scope definition, not just technical complexity

### 4. Live Artifacts for Real-Time Dashboards
Dashboards refresh dynamically using connector data from Spotify, Gmail, and Calendar—artifacts displaying constantly updated information.

### 5. Building Hardware with Claude Code
A $20 physical device created without hardware experience, featuring a button to approve Claude actions. Demonstrates accessibility of hardware prototyping.

### 6. The Importance of Politeness
Felix emphasizes treating Claude respectfully affects interaction quality and reflects personal values.

### 7. Children Excel at AI Usage
Kids build games and interactive stories without learned limitations about computing capabilities that constrain adults.

## Tools Featured
- Claude Cowork
- Claude Code Desktop

## Philosophical Insight
"The biggest gap remains people's uncertainty about what problems AI can actually solve." Mental barrier, not technical.
