## Part 1: Sonnet 5 Benchmark Review (Claire Vo)

Claire conducted extensive testing of Anthropic's new Sonnet 5 model using a custom evaluation framework called "How I Bench." She ran 64 generations comparing Sonnet 5 against Sonnet 4.6, Opus 4.8, GPT-5.5, and Gemini 3 Pro across multiple task categories.

### Key findings

- Sonnet 5 is priced closer to previous Sonnet models than to Opus: $2/$10 per million tokens
- Claire ranked Sonnet 5 lower than expected in personal preference assessment
- Human judgment and automated LLM-as-judge evaluations diverged significantly
- Automated evaluators rated Gemini 3 Pro highest; Claire's assessment placed Sonnet 4.6 first (superior personality in agent interactions)

### Recommendations by use case

- GPT-5.5: product requirement documents
- Sonnet 4.6: prototyping
- Opus 4.8 or Sonnet 5: codebase navigation

## Part 2: Managing Autonomous Coding Agents from Mobile (Alessio Fanelli, Kernel Labs)

Fanelli demonstrated operating autonomous agents via phone using OpenAI Symphony, Linear, and cloud VPS infrastructure. Illustrated the evolution from "agent prompter" to "agent manager" as the critical operational shift.

### Key insights

- Tracking token costs per task reveals efficiency patterns
- Keeping skills files concise prevents instruction contradictions
- Providing agents with better visual perception (screenshots, diffs) extends autonomous runs significantly
- Example: using Codex with browser access to identify underpriced Pokémon cards for arbitrage trading — demonstrating how AI compresses traditional information advantages previously requiring scale and domain expertise
