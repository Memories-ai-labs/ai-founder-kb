# Claude Mods: Flipping the Harness Inside Out
# URL: https://www.latent.space/p/claude-mods
# Date: 2026-10-21
# Source: Latent Space

## Author
Dan McAteer

## Summary

Essay arguing that as AI models absorb more of the agent harness, the remaining programmable layer now faces humans rather than machines. Claude Code Mods are TypeScript/JavaScript plugins that make this "Attention Interface" layer programmable — deciding when agents interrupt users, what they show, and what decisions they ask users to make.

## Key Points

- **What Claude Mods are:** Plugins for Claude Code made of TypeScript or JavaScript functions. They respond to events like prompts, tool calls, and interface renders, and can change how those events are shown or handled.

- **The Harness Reversal thesis:** As models absorb more agent functionality, the harness no longer points at the machine — it points at the human operator. Mods make that human-facing layer programmable. The author calls this the "Attention Interface."

- **Built-in mods from Anthropic:** Six ship with Claude Code, including *You Should Know* — a side agent that flagged uncommitted work the author would otherwise have discarded.

- **Author's mod:** *Next Steps Supervisor* — runs after certain turns and offers clickable next-step suggestions. Part of the open-source ModSmith plugin.

- **Three interface paradigms compared:**
  1. ChatGPT Intelligent UI: model designs interfaces within OpenAI's component library
  2. Cursor PR Routing & Approval: team sets policy within a fixed workflow
  3. Claude Mods: user and agent build the interface in code — most open, most powerful

- **Downsides flagged:** Mods can be noisy, add token cost, and run with the user's permissions without a sandbox. Author recommends reading any third-party mod's code before installing.

- **Future outlook:** Author sees a future where the harness notices user friction from session transcripts and suggests mods to fix it. The programmable attention layer could become a major differentiator between AI coding environments.

## Significance for AI Founders
This essay captures a key architectural shift: the competitive frontier is no longer just model capability but the human-AI interaction layer. Builders should think about what "attention interfaces" they're designing.
