## Episode Summary

Mihail Eric teaches "The Modern Software Developer" (CS146S) at Stanford and leads AI at Monaco. This episode covers how Stanford is retooling engineering education for the agentic era, and what junior engineers need to learn now.

**Key topics:**

**Stanford's CS146S course:**
- Second run brought open-source maintainers in to review student patches
- Ten-week syllabus covering what junior engineers need now
- When agents can complete traditional coding exercises in one prompt, teaching must shift toward understanding unfamiliar codebases, proposing changes, and defending them to reviewers

**How coding agents work internally:**
- The agent loop, tools, and harness
- Context engineering for large codebases
- Skills for understanding AI-generated diffs

**Monaco's products:**
- Agent workspaces and code review tooling
- On-call agent connected to Datadog and GitHub
- Code review becoming the bottleneck as code generation speeds up

**Agentic infrastructure:**
- Background agents (Stripe's Minions referenced)
- MCP infrastructure
- Building a "software factory" and what work remains for developers

## Key Takeaways for AI Engineering

1. **Assignments need to change.** Teaching has to shift toward understanding unfamiliar codebases, proposing changes, and defending them to reviewers.
2. **Understanding the agent's internals helps.** Knowing how the loop, tools, and harness fit together makes it easier to use and debug coding agents.
3. **Review is the constraint.** As generation outpaces review, teams need better ways to verify and understand the code they ship.
4. **Build versus buy is a deliberate choice.** "You buy to learn, and you build to keep."
5. **Repos need to be agent-ready.** Clear context, workspaces per agent, integrations with observability and version control.
6. **Guardrails matter.** Permissions, dependency management, and security need explicit attention once agents act autonomously.
