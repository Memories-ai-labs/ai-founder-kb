## Key Topics

**Core Concept — System One Models:**
Jev is a new class of "System 1" models designed for software integration rather than chat interfaces. These are "machine-native" models optimized for "intelligence per dollar," with code as the direct consumer rather than humans reading responses.

**RLCD vs RLHF:**
TypeSafe uses Reinforcement Learning for Calibrated Decisions (RLCD) as an alternative to traditional RLHF. Diogo emphasizes that "the North Star" matters more than algorithms — RLCD targets programmatic AI without human-in-the-loop dependency, addressing reliability through calibrated probability estimates rather than human preference ratings.

**Mode Collapse Problem:**
RLHF causes models to drop minority modes, creating overconfident predictions. This makes models unreliable for decision-making, particularly when embedded in software dependencies where refusals become systemic failures.

**API Safety Philosophy:**
TypeSafe rejects safety-aligned refusals in APIs, treating intelligence as infrastructure (like databases) rather than consumer products. Developers should have maximum flexibility for their use cases.

**Data Lab, Not Model Lab:**
TypeSafe prioritizes synthetic, carefully curated data over massive pre-training. "Right task and right data" matter more than compute scaling. Focus on general-case robustness rather than overfitting.

**API Primitives:**
Three new types (Choice, Noulli, Score) map directly to programming constructs: switch statements, if statements, and threshold operations. Structured JSON inputs replace template-based system messages.

**Reliability vs. Determinism:**
Robustness (consistent outputs for similar inputs) matters more than determinism (identical outputs for identical inputs). TypeSafe trades determinism for better intelligence-per-dollar metrics.
