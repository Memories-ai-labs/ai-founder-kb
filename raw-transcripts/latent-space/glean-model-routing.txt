## Summary

This article explores how model routing — the practice of automatically selecting the optimal AI model for a given task — has become a critical capability for enterprise AI deployments. Glean, valued at $7.2B with $300M ARR, uses a three-tier model selection approach allowing employees to choose models, administrators to set restrictions, or the system to automatically select based on task requirements.

## Key Themes

**Model Routing as Enterprise Infrastructure**
- Enterprise AI buyers are rejecting single-provider lock-in; multi-model orchestration is now a purchasing requirement
- Glean claims 4x cost-effectiveness versus Claude Code via intelligent routing
- Arvind Jain: "Open source is an order of magnitude cheaper" for many tasks
- Open-source models are gaining enterprise adoption rapidly, driven by cost pressure at scale

**Glean's Waldo Agentic Search Model**
- "Waldo" is Glean's proprietary agentic search model
- Reduces search latency by 50% while decreasing token usage by 25%
- Key innovation: routes retrieval tasks to a specialized model rather than a frontier general model

**Human Feedback Loops at Scale**
- Glean has 80% employee adoption at companies like Zillow
- That adoption generates continuous feedback data enabling routing improvement
- Feedback flywheel: more usage → better routing → lower cost → more usage

**Broader Market Signal**
- Organizations are increasingly demanding flexibility to swap models as the landscape evolves
- The routing layer is emerging as a distinct product category between the model and the application
- Frontier model pricing cuts (OpenAI 50% cut Aug 18) accelerate adoption but also make routing economics more complex

## Context for Founders

The model routing layer represents a key infrastructure bet: if multi-model orchestration becomes standard enterprise architecture, whoever owns the routing layer captures durable margin. Glean's 4x cost efficiency claim is a validation of routing as a real product, not just a feature. Founders building on top of LLMs should consider whether their product depends on a specific model or can benefit from routing.
