## Episode Summary

Zeno Rocha (Resend) joins swyx to discuss how developer tooling companies need to redesign their products for the agentic era.

**Key topics:**

**Developer adoption before model choice:**
Resend's early distribution came from React Email, an email template tool that developers could use with other providers like SendGrid. Some of Resend's code was already in users' repos before they switched providers. This "code already in repo" distribution strategy is a key moat.

**Agent Experience (AX) design:**
- Resend's pricing page has a Markdown version that agents can read in one request
- AEO study found Claude Code recommended Resend first in most extracted cases, while SendGrid was ranked first far less often
- A later broader study showed more competition, with Postmark leading for most models

**MCP design philosophy:**
- Resend's MCP server grew from ~20 tools to >80, aiming to match what users can do in the dashboard
- Discussion contrasts this with Cloudflare's two-tool Code Mode design (search() and execute())
- Zeno suggests inspecting real tool results to see how much data the model actually needs

**Deliverability and trust:**
- Shared vs. custom click-tracking domains
- Why abuse on a shared domain can hurt legitimate senders
- Keeping a free tier despite spam risk

**Company stats at recording:**
- 4.3 million users
- 120,000 paying customers
