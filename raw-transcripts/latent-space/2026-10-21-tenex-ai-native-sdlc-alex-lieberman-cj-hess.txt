# AI for the Fortune 2000: How Tenex Builds an AI-Native SDLC
# URL: https://www.latent.space/p/tenex
# Date: 2026-10-21
# Source: Latent Space (Podcast — AI Engineer New York)

## Guests
- Alex Lieberman, Co-founder, Tenex
- CJ Hess, Special Projects Lead, Tenex

## Summary

Tenex is an applied AI firm (75 people) helping Fortune 2000 and mid-market companies move from AI-absent to AI-native. The episode covers outcome-based engineer compensation, AI productivity metrics, enterprise AI adoption patterns, and the MetaHarness system for agent context management.

## Key Points

### Company
- 75 people, mostly engineers and "AI strategists" (technical consultants)
- Customers: split evenly between Fortune 2000 and mid-market
- Demand has shifted from pure development shop toward broader AI transformation advisory

### Outcome-Based Pay
- Engineers paid using story points; concerns about inflated estimates or low-quality code have not materialized
- AI strategists incentivized on client retention and growth
- Harder challenge: compensating non-coding work (architecture, client discovery, deciding what to build)
- Story-point values recalibrated ~quarterly

### Productivity Metrics
- Engineer output roughly doubled this year (Alex's estimate)
- Highest-paid engineer earns ~4x the lowest-paid one

### Tooling and Models
- Primary model: Opus 5.5 for engineering work
- Codex often used for code review
- Alex works mainly through AMP (AI-native development environment)

### MetaHarness System
- Internal system of shared skills, structured repo documentation, and a CLI
- Plans, decisions, and agent logs are checked into Git
- Context lives in the repo rather than in people's heads — key for maintaining institutional memory as agents and people work together

### Enterprise AI Adoption (Alex's estimates across ~100 prospects)
- ~90% have rolled out a general-purpose LLM
- ~60% have done training/fine-tuning
- ~50% have coding agents
- ~5% run agents in production for non-engineering work

### Key Insight: Standardize Before Automating
"You can't automate a process that does not exist." — Alex Lieberman
Enterprises must standardize workflows before AI can operate reliably within them.

### Permissions and Data Access
- CIOs and CISOs struggle to control what data AI tools can access
- Tenex built bespoke AI gateway and permissioning solutions, now productized

### Kill My SaaS Experiment
- Internal hackathon: replace a speaker-management tool quoted at $43,000/year
- The team that won with human judges placed 19th on AI judge's leaderboard
- Reveals: meeting functional scenarios ≠ winning user preference

### Vertical AI Debate
- Alex: bearish on vertical AI products due to enterprise complexity and difficulty of achieving software margins on one-of-one solutions
- Host: pushed back citing Harvey, OpenEvidence, Bloomberg — proprietary data + specialized interfaces + workflow habits create durable value

### Jobs and Hiring
- Both guests expect AI to displace and reallocate work, not eliminate it
- Tenex hiring: forward-deployed engineers, AI strategists, engineers for special projects (internal tooling, background agent platforms)
