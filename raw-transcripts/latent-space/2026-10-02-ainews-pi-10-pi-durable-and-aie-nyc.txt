## Pi Framework Releases

**Pi 1.0** introduces several developer-focused features:
- Native MCP support with Jev and image model integration
- Virtual model extensions capability
- Deferred tool loading and cache warming for Anthropic models
- "Mid-conversation system messages" allowing "transcript-aware prompt and tool changes"
- UI improvements including new theme and full-screen mode default

**Pi Durable** ports Pi to TypeScript with significant architectural improvements:
- Checkpointed task recording enabling automatic resumption after crashes
- Cross-platform JavaScript runtime support with pluggable storage backends
- Parallel conversation handling without blocking
- Custom extension bundling for prompts and tools
- Automatic message compaction to maintain token limits
- Multiplayer state synchronization alongside conversation transcripts
- "Tool and extension code can be updated dynamically while the agent is running"
