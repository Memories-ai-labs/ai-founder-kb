## Episode Summary

Arca is an AI-native wealth management firm. Aman Singh, lead AI Engineer, discusses how they use long-horizon agents for financial work — with the key insight that "agents prompt people more than people prompt agents."

## Key Points

**Long-horizon agent architecture:**
- Agent tasks can take up to ten days end-to-end, with many handoffs and human decision points
- Arca built a persistent memory system that tracks each client's status and responsibilities across the full workflow
- The system maintains state across multi-day, multi-step processes

**Human-in-the-loop design:**
- Agents handle most background analytical work
- Human advisors make all final decisions — especially trades and money movement
- Safety rules are deterministic (not AI-decided): certain action classes require human sign-off with no exceptions

**Model selection:**
- Primary AI provider: Anthropic (Claude)
- Also uses OpenAI models
- Built their own harness that picks models based on internal benchmarks and preserves the option to switch providers
- Model-agnostic architecture is a deliberate design choice for resilience

**Technical implementation:**
- Agents query financial data by writing code in sandboxes
- Generated code is converted into a strict format with guardrails before it reaches back-end systems
- A "meta-agent" analyzes advisor feedback and agent traces to suggest improvements to the harness itself (self-improving system)

**Representative example:**
- A $100,000 tax bill scenario was used to demonstrate multi-step agent workflows involving client analysis, proposal generation, advisor review, and execution

## Key Quote

"Agents prompt people more than people prompt agents" — framing the human-AI relationship in financial services as agents surfacing recommendations and humans deciding.

## Significance for AI Founders

This is one of the clearest real-world examples of:
1. Long-horizon (multi-day) agentic workflows in production
2. Deterministic safety boundaries combined with flexible AI reasoning
3. Meta-agents improving the system based on feedback loops
4. Enterprise-grade, AI-native financial services architecture
