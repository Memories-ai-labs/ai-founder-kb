# Railway: The Agent-Native Cloud — Jake Cooper
# Guest: Jake Cooper, Founder/Conductor of Railway
# URL: https://www.latent.space/p/railway
# Date: 2026-05-20
# source: Latent Space Podcast

## Episode Overview

Railway is positioning itself as the agent-native cloud. Key metrics: 3M users, 100K signups/week, 35-person team, $124M raised, 70% margins on bare metal with 3-month payback. $200K+ monthly coding agent spend across the company.

Core philosophy: "The activation energy to ship something to production should be near zero."

## Key Themes

### Agent-Native Infrastructure
Railway positions for an agent-dominated future where "agents are the next dominant software species." Requires infrastructure supporting versioning, observability, rapid branching, and 1,000x scale vs. human-developer needs.

### The Long Build (2020–2026)
- 18 months of personal Discord engagement with each signup
- Survived period losing "$500K/month" while maintaining $20M bank account
- Strategic decision to cut free tier and rebuild business model

### Infrastructure as Competitive Advantage
- Owns multiple bare metal data centers globally (Singapore, multiple regions)
- Can burst into AWS, GCP, Oracle as needed
- Rebuilt entire network overlay in one weekend for five-cloud architecture
- Hardware appreciated in value as RAM prices climbed

### The Dying Pull Request
Jake states the "pull request is dying," replaced by prompt requests with agent code review, feature flags, and incremental rollouts.

### CLI Over Canvas
Visual canvas remains important as output/dashboard, but CLI becomes primary interface for agent interaction.

### Central Station: Context Aggregation
Internal tool clustering customer feedback, incidents, support issues dynamically—routing to relevant engineers based on context and commit history.

### Economics of Scale
- Cloud payback: 3 months vs. renting
- Coding agent spend: ~$25K/month for Jake personally; $200K+ company-wide
- "If you're writing code by hand, you're doing this wrong"

## Notable Quotes

"The dominant species over the next 10 years: assembly → C → C++ → JavaScript → words."

"Pull request is definitely dying" — replaced by feature-flagged, incrementally rolled-out changes.

"Whatever is required, however deep we have to go, we'll go all the way down to the kernel's TCP/IP stack."

"If hyperscalers copy homework, you become them over time. You need a core thesis for why this business exists now."

## Technical Highlights
- Multi-cloud orchestration across Railway metal, AWS, GCP, Oracle
- Progressive rollouts from low-impact to enterprise customers
- Production forking with PII transformation and copy-on-write databases
- BPF hooks for custom kernel networking and volumes
- Self-replicating infrastructure (agents authenticated as current box, calling Railway CLI)

## Future Outlook
Jake believes agents drive a fundamental shift in software development over the next decade. Bottleneck shifts from technical capability to inference cost and organizational CFO acceptance. Railway's roadmap accelerated dramatically through agent-assisted coding.
