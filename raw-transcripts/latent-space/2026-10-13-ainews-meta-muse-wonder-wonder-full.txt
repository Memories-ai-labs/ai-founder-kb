## Meta Superintelligence Labs releases Muse Wonder and Wonder Full

- **Models:** Muse Wonder (codename "Watermelon") and Muse Wonder Full — Meta's first near-frontier release, ~14 months after MSL founding.
- **Availability:** Wonder via Meta Model API and Muse Code; Wonder Full limited to Muse Code subscribers. Wonder will also power Muse personal-agent product.
- **Pricing:** $4/M input tokens, $0.20 cached input, $20/M output; 1M-token context window.
- **Benchmarks (Artificial Analysis Intelligence Index v4.3):** Wonder Full: 56, Wonder: 52 (vs. Claude Opus 5.5 leading at 58). Vals AI ranks Wonder Full #5, Wonder #10.
- **Meta's claims:** Wonder Full at 57.5% on SWE-Marathon (vs. 46.3% for Opus 5.5); 79.0% on DeepSWE (vs. 74.2%). Features include Active Memory and Active Focus.

## Community reactions

- Positive: Early testers praised speed and token efficiency. Theo ranked it alongside Opus 5.5.
- Skeptical: scaling01 estimated Meta is 3–6 months behind OpenAI and Anthropic. Critics noted weak 3D and SVG demos; Alexandr Wang admitted no explicit 3D training.
- Launch issues: Both models drained Muse Code usage quotas abnormally fast on launch day; bug fixed same day, quotas reset.
