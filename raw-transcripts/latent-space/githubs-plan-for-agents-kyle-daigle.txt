## Episode Summary

Kyle Daigle (COO/CMO Developer, GitHub) joins Swyx to discuss how GitHub is adapting to unprecedented 14x year-over-year growth driven by AI coding agents, now processing 275 million commits weekly (on pace for 14 billion annually). The conversation covers infrastructure scaling crises, evolving developer trust models, and GitHub's platform strategy as agents reshape software development.

## Key Themes

### AI-Driven Growth Crisis
GitHub's growth is "astronomical" — from 1 billion annual commits in 2025 to 275M/week in 2026. Agentic coding tools generate massive code volumes, straining infrastructure originally designed for human-speed development. The company is rewriting database permission layers ("MySQL One"), job queuing systems, monorepo infrastructure, and compute layers for Actions — what Daigle calls "diagonal scaling" (not vertical or horizontal, but architectural rewrites of 10-15 year old services).

### Internal AI Workflows
Kyle uses AI agents retrospectively across company data: "Go through all PRs, everything posted online, last three months, Obsidian notes, Teams transcripts, Slack" to analyze messaging and plan adjustments. He runs "15 agents on Saturday" for recursive analysis across company history.

### Micro-Skills Over Mega-Skills
GitHub moved from large, brittle automation tools to atomic micro-skills doing "one thing very well." These are composed into workflows rather than monolithic solutions that break when business needs change. Micro-skills are distributed through CLI tools that access company context via Slack, Teams, email, and GitHub itself.

### Pull Requests & Trust Evolution
As agents generate most PRs, review processes shift. The "human trust signal" remains critical — Mitchell Hashimoto's vouching system is one community-driven approach. Trust is fundamentally social; no universal technical solution exists. "Slop forks" and supply chain security require community-governed rather than top-down mandated solutions.

### Developer Definition Evolution
GitHub's 200+ million accounts span professionals to newcomers using AI. Kyle resists gatekeeping: "If you create code and run it, you're a developer." New cohorts gravitate toward weekend projects rather than maintaining legacy codebases.

### Copilot's Transformation
From code completion to an SDK powering multiple form factors (CLI, desktop app, cloud agents), Copilot handles security remediation, issue automation, documentation checking. Focus shifted from fine-tuning to agentic coding across full SDLC workflows.

### Ambient AI Vision
Future AI understands full work context without explicit instruction — reading emails, specs, conversations, understanding business priorities — and proactively surfaces relevant information. Requires solving "taste" and "judgment" codification, near AGI-adjacent research.

### Platform Strategy: WorkIQ & FoundryIQ
Enterprise context engines querying M365 assets without creating security/compliance risks. Enable agentic workflows at large companies where speed collides with governance requirements. Microsoft dedicates engineering to OpenClaw for OS-level sandboxing and cross-platform agent support.
