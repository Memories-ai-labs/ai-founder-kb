## Show Notes

Guest: Kyle Daigle, COO and CMO of Developer for Microsoft (GitHub)
Published: June 2, 2026

GitHub pioneered modern AI coding with Copilot, leading to explosive growth in agentic development. This growth has strained GitHub's infrastructure, originally designed for human-speed development.

**Kyle's Expanded Role**
Now serving as both COO of GitHub and CMO of Developer for Microsoft, bringing developer expertise across the broader Microsoft ecosystem.

**AI-Powered Workflows**
Kyle uses agents to analyze company context by reviewing PRs, transcripts, Slack messages, Teams data, and Obsidian notes for strategic decision-making.

**Micro vs. Mega Skills**
Shift from large, complex skills to small, atomic skills that do one thing well and can be orchestrated together.

**GitHub's Growth Crisis**
1.4 trillion percent growth in agent-generated code; 275 million commits weekly; infrastructure built for human developers now handling exponential agent traffic.

**Scaling Challenges**
Database permissioning bottlenecks, monorepo performance issues, job queuing problems, and the need for horizontal and vertical infrastructure expansion.

**Copilot Evolution**
Moving from code completion to comprehensive coding agents across CLI, desktop app, and cloud environments using unified SDK.

**Trust in Open Source**
Vouching systems, AI-generated contributions, PR reviews, and maintaining security as agent-generated code floods repositories.

**Ambient AI Vision**
Future where AI understands developer context across all information sources and proactively assists without explicit requests.

**OpenClaw and Platform Components**
Microsoft investing in sandboxing, Windows integration, and OS-level support for agent infrastructure.

**Enterprise Adoption**
WorkIQ and FoundryIQ as context engines enabling powerful AI assistance while maintaining security compliance at large organizations.

**Notable Quote:**
"This is the best and most exciting time" while simultaneously "it's a hard time" for GitHub operations, reflecting both opportunity and infrastructure strain.
