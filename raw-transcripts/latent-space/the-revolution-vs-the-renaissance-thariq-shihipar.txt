Guest: Thariq Shihipar (from Anthropic Claude Code team, announcing move to OpenAI)

## Episode Summary

The episode centers on the idea that AI can make software cheap enough to produce in volume while still leaving time to make one thing "feel right." Thariq shows this with a fighting game where he edits a rock's size in the `/human` folder and immediately tries the throw. He also describes a Mac Dock that switched modes, which he used and then stopped using, realizing he cared more about noticing when he got distracted. The conversation covers how his views on coding agents changed, how a decision model can choose from actions a designer defines, and who decides which experiments deserve compute.

## Key Themes

- **Revolution vs Renaissance**: AI makes software cheap to produce at volume; the question is whether we spend the saved time making things feel right (Renaissance) or just shipping more (Revolution)
- **The /human folder**: A design pattern for agentic coding — editable parameters humans can tweak in real-time during gameplay/use; enables rapid iteration loops
- **Software as craft**: Even in an era of cheap AI-generated code, the value of making one thing feel exactly right persists
- **Decision models**: Architectures where AI chooses from a designer-defined action space rather than generating arbitrary code
- **Personal software**: The return of software built for one person's specific needs, now economically viable at AI code generation speeds
- **The land/water test**: A framework for evaluating agent actions
- **Autoresearch**: Automated research workflows at scale
