# Lovable CTO: The Future of SaaS Is Apps That Agents Can Use
# URL: https://www.latent.space/p/lovable-future-of-saas
# Date: 2026-08-26
# Source: Latent Space (Substack)
# Guest: Fabian Hedin (CTO, Lovable)

## Summary

Fabian Hedin, CTO of Lovable, discusses how Lovable is transitioning from an AI-powered app-building platform toward enabling "capabilities" — discrete functions that AI agents can access directly through MCP servers, bypassing traditional user interfaces.

## Key Points

**Business metrics:** $500M annualized revenue run rate, 60M+ projects created, $400M Series C led by Menlo Ventures, $13.3B valuation.

**The vision — "A digital brain for your team":** Rather than users navigating between multiple applications, a single agent interface orchestrates work across various capabilities. Hedin describes the goal as moving from UI-centric SaaS to agent-callable capabilities.

**Technical approach:** Lovable exposes selected app functions as agent-accessible tools through hosted MCP servers. This creates dual interfaces — traditional human UI and agent-callable capabilities — within a single application.

**Security:** "App user connectors" preserve individual user identity and permissions, storing encrypted credentials server-side rather than exposing them to generated applications.

**Competitive positioning:** Hedin suggests Lovable's advantage is being "the best place to build the capabilities that agents need," even as competitors like Vercel pursue similar visions.

**Advice to SaaS founders:** Companies must "focus more on providing the shovel for AI to use their capabilities" rather than resisting agent-driven consolidation. The implication: every SaaS company needs an MCP surface, not just a UI.
