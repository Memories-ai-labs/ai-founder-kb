## Overview

In-depth technical analysis of OpenAI's ChatGPT Work, released July 9, 2026. This agent product for knowledge work consolidates years of scattered experimental tools into an integrated platform designed for a billion-user audience.

## Core Architecture

Work functions as "an agent for knowledge work" that integrates with productivity apps like Slack, email, and CRM systems. It operates on the Codex harness and runs within isolated cloud microVMs — Pro accounts receive 8 CPUs and 20GB RAM. The platform generates interactive artifacts (spreadsheets, documents, websites) and maintains a persistent workspace directory per task.

## Key Technical Features

**Persistence & Memory:** Unlike open environments, Work balances agent autonomy with safety guardrails. Each task receives a dedicated workspace directory where the agent operates freely, but cross-task continuity flows through ChatGPT's product layer rather than direct filesystem access. "The agent has broad freedom within a task, but continuity across tasks runs through an opinionated ChatGPT product layer."

**Proactivity:** Work suggests personalized tasks drawn from user context, analyzing calendars and emails to propose preparation materials before meetings.

**Browser Capabilities:** Controls a remote Chrome service, enabling form completion and website navigation — capabilities unavailable in standard ChatGPT. Cloud-based browser sessions face site-detection challenges that local operation avoids.

**Scheduling:** Automated tasks run standalone or within existing conversations on recurring schedules, supporting workflows from daily briefings to monitoring operations.

**Plugin Ecosystem:** Over 1,000 plugins connect external services, though plugin discovery remains underdeveloped — the system rarely suggests relevant but uninstalled integrations.

## Unresolved Tensions

Three design questions pending resolution before Work's scheduled integration with standard Chat later in 2026:
1. Cloud versus local computing priorities
2. Agent autonomy scope
3. User onboarding strategy
