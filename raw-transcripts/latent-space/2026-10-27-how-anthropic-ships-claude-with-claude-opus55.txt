# How Anthropic ships Claude with Claude: Separating the Brain from the Hands
# URL: https://latent.space/p/opus55/
# Date: 2026-10-27
# Source: Latent Space (Conversation / Podcast)

Guests: Katelyn Lesse (Anthropic Head of Engineering), Angela Jiang (Anthropic Head of Product)
Topic: Opus 5.5 launch and how Anthropic builds the Claude Platform

**Key insights:**

**Launches are API launches too.** Anthropic adjusted its API to make distillation harder, requiring preserved thinking blocks across turns. Shipped a new compaction feature for harness builders, and worked with open-source harness maintainers on changes.

**Safety now shapes most launch work.** Decisions include data retention policies, per-model safeguards, and "trust grants" that control who can access restricted models or programs. Anthropic built a single control that could pull back access broadly if needed.

**Brain and hands architecture.** In Claude Managed Agents, the harness runs on a durable server and sandboxes spin up only when code must execute. Credentials sit in a separate vault; the agent sees only placeholders. A proxy injects real credentials on outbound requests, and egress controls restrict where sandbox traffic can go. Design was driven by latency and reliability — security was a major benefit.

**Dreaming and multi-agent patterns.** Dreaming is a managed agent that reviews another agent's prior work and writes memories back. Anthropic plans to expose underlying primitives for developers to build their own multi-agent strategies.

**Evals guidance.** Recommend larger eval suites, starting simple, treating engineering like research: define a goal, formalize it as an eval, investigate failures. "The eval itself is often wrong."

**CPU and Rust.** Messages API was rewritten in Rust. Shadow traffic used to verify matching outputs. Reported ~40-50% CPU savings and 10-20% lower time to first token.
