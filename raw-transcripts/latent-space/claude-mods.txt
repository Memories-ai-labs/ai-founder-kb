What Claude Code mods are: TypeScript/JavaScript functions that respond to events (prompts, tool calls, interface rendering) and can change how the Claude CLI and Desktop display and behave.

Core argument: As models absorb more of the agent harness, the remaining layer faces the human — the "Attention Interface" — which decides when the agent interrupts you, what it shows you, and which decisions it needs from you.

Built-in mods shipped by Anthropic: agents-md, diff, plugin-authoring, sec-default, telemetry, and you-should-know (off by default).

Examples:
- You Should Know: side agent that flagged uncommitted work the author would have lost by discarding demo edits.
- Next Steps Supervisor: runs after turns that edit files, run commands, or make 8+ tool calls, then offers suggested next steps as clickable buttons. Part of the open-source ModSmith plugin.

Comparison with other products:
- ChatGPT Intelligent UI: model generates an interface per answer, using a component library OpenAI built.
- Cursor PR Routing & Approval: applies team policy through fixed review workflow.
- Claude Mods: let the user and agent build the interface in code — more control, more effort.

Downsides:
- Noise: supervisor triggered on 99 of 111 turns; author started skimming it.
- Cost: each check adds token overhead (estimated in mod's README).
- Trust: mods run with user's permissions and aren't sandboxed — read third-party code before installing.

Future direction suggested: a harness that reads session transcripts, spots repeated friction, and proposes or refines mods to address it.
