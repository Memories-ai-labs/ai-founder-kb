## Overview

Matt Pocock, creator of the popular "AI Skills for Real Engineers" GitHub project (220,000+ stars), introduced a new skill called /wayfinder designed to help developers and AI agents navigate projects with unclear end states.

## Purpose

Pocock developed wayfinder to eliminate constraints during project planning. Rather than managing multiple planning sessions individually while monitoring token usage and context windows, the skill orchestrates planning across multiple threads — including prototyping, research, and consolidation.

## Core Components

The skill operates on three key concepts:

- **Map**: A centralized document capturing all previous decisions
- **Ticket**: Specific work assignments for individual sessions
- **Session**: The grilling sessions managed by the orchestrator layer

## Ticket Types

Wayfinder supports four ticket categories:
1. Grilling sessions
2. Prototypes
3. Research tasks
4. Broad human tasks that agents cannot execute

## The "Fog of War" Concept

Pocock explained that "you can't quite decide everything right at the start." Wayfinder enables iterative decision-making where choices progressively expand understanding, similar to exploring an undiscovered map. This approach helps teams address uncertainty systematically rather than through exhaustive upfront planning.

## Terminology and Communication

Pocock emphasizes finding "the right words" to establish shared understanding between humans and agents. He's developing an AI coding dictionary to ensure consistent terminology across all skills and courses.

## When to Use Each Skill

- **Grill-me**: Single-session planning with a visible path forward
- **Wayfinder**: Projects obscured by uncertainty and complexity

## Signal for AI Founders

This represents an emerging meta-layer of AI workflow tooling: skills/prompts that orchestrate other skills/prompts. The 220,000-star GitHub project signals strong developer appetite for systematic, reusable AI planning frameworks. The "fog of war" framing and ticket-based decomposition could be a model for AI-native project management tooling.
