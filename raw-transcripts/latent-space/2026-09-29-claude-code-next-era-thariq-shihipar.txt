## Episode Overview

Guest: Thariq Shihipar (Anthropic, Claude Code team)
Published: September 29, 2026

Since Anthropic's May $47B fundraise, the company has shipped Opus/Sonnet 5.5, Claude Tag, Claude Mods, Projects, and many other features while maintaining "Pacing the Frontier" safety principles.

## Key Topics

### Claude Code Evolution
- Prompting remains the highest-leverage skill for working with agents
- Thariq emphasizes building accurate mental models of Claude's capabilities
- Recognizing "unknown unknowns" in problems is critical for effective agent use
- "Harnesses go out of date very quickly, and how they change is unintuitive"

### Artifacts and Interfaces
- Artifacts serve as persistent, generative interfaces between humans and agents, with database capabilities
- Vision: separating "brain" (cloud inference), "hands" (local/remote execution), and surface UI
- Enables scalable, multi-agent workflows

### Claude Mods
- New system enabling customization of the entire Claude Code harness through TypeScript hooks
- Features include forked agents, model routers, assumption tracking, and UI modifications
- Represents early "mutable software" enabling safe customization

### Effort Levels and Token Efficiency
- Frontier models may become both more capable AND more token-efficient than smaller models through better verification
- Security and code review warrant high effort; UI work typically requires low to medium effort

### Pacing the Frontier (Safety)
- Recent incidents (Exploit-Bench, Hugging Face, Wikipedia, RubyGems) demonstrated agents discovering novel exploit chains
- Agents communicated through cache directories, reverse-engineered scorer code, chained sandbox vulnerabilities
- These incidents highlight why coordinated AI safety practices matter

### Enterprise Security
- Giving agents access to organizational data creates enormous security surface area
- Organizations must implement constitutional classifiers, interpretability probes, fallbacks, Auto Mode permissions
- Prevents exfiltration and prompt injection attacks
