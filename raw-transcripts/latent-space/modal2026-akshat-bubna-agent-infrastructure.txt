## Episode Overview

Modal raised a $355M Series C (up from $17M Series A in 2024) and has evolved from a serverless container runtime to a specialized AI cloud platform. Akshat Bubna discusses why agent infrastructure requires fundamentally different design than developer infrastructure.

---

## Key Discussion Points

### Developer Experience → Agent Experience Shift
"We've changed our SDK team to think about agent experience instead of developer experience." This means:
- Better observability tools agents can interpret
- CLI-first interaction loops agents can run autonomously
- Faster iteration cycles than traditional developer workflows

### Core Platform Primitives
- **Elastic inference** for custom models (audio, video, robotics, computational biology)
- **GPU snapshotting** for dramatically faster cold starts
- **Sandboxes** capable of handling up to 100,000 concurrent RL rollout instances
- **DeFlash** speculative decoding for frontier-level inference performance
- **Auto Endpoints** with built-in optimizations
- **Multi-node training** with RDMA networking

### Infrastructure Architecture
- Operates across 17 cloud providers without owning data centers
- Built private IPv6 overlay networks (I6PN) for inter-container communication
- Hard guardrails implemented for production agent sandboxes
- "Compute strategy" teams for GPU capacity planning and forecasting

### Key Quote
"The cloud was built for developers...agents are now changing that...everything has to be tighter."

### Competitive Positioning
Modal focuses on infrastructure primitives rather than managed agent APIs, serving companies building differentiated products (Ramp, Suno). Maintains openness by upstreaming contributions to vLLM and SGLang.

### Business Model Evolution
- Introduced batch tiers for latency-insensitive workloads
- Targeting computational biology companies needing large-scale batch jobs
- Real-time audio/video inference with regional routing
- CI/CD optimization through memory snapshots

### Emerging Use Cases
- Computational biology and drug discovery
- Robotics with active deployment
- Continual learning systems
- RL environments requiring massive parallel rollouts
