## Episode Summary

Recorded live from Cloudflare Connect. Dane Knecht, CTO of Cloudflare, discusses how AI is transforming the security landscape — both for attackers and defenders — and how the agentic web requires rethinking internet infrastructure and security models.

## Key Topics

**Rising vulnerability volume:** Serious vulnerability disclosures have accelerated from roughly once a year to weekly. Security may consume a majority of engineering time for an extended period.

**AI-powered attackers:** Many recent high-profile vulnerability discoveries come from individuals using AI agents, not just nation-states. The attacker landscape has democratized dramatically.

**Zero trust posture:** Organizations that shifted from perimeter-based ("castle and moat") security to zero trust are better positioned for the agentic era.

**Software development lifecycle shift:** Security must be embedded at each step of development, not bolted on. Reducing attack surface is a foundational first principle.

**Agentic web economics:** Humans and AI agents now share the same web infrastructure, creating economic challenges around content monetization that may require new micropayment models.

**Cloudflare initiatives:**
- Conference monetization gateway
- Signals (collaboration with OpenAI to help agents discover new content)
- Cloudflare OS (internal AI platform released as open reference architecture)
- Intern program: ~1,000 interns, hiring for curiosity

**Open vs. closed models:** Security capabilities will eventually spread broadly through open source, democratizing both offensive and defensive capabilities.

**Engineering team restructuring:** Cloudflare has reorganized for AI-first work, including token budgeting practices and restructured team priorities.
