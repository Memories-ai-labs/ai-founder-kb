## Highlights

**1. Sakana AI Fugu: Model Orchestration Becomes a Product Category (June 22)**
Japan's Sakana AI released Fugu, a language model trained specifically for multi-agent orchestration — not a general-purpose model, but a model that knows how to delegate, coordinate, and synthesize work across other LLMs. Fugu Ultra claims benchmark parity with Anthropic Fable 5 and GPT-5.5, and is explicitly positioned as a US-export-control-safe alternative. With 230 HN upvotes, this signals an important pattern shift: orchestration logic is no longer just framework code (LangGraph, AutoGen) but is becoming a trainable capability. For AI founders: the agent coordination layer may become a specialized model problem, not just a software problem.

**2. OpenAI Daybreak Expansion: From Detection to Remediation (June 22)**
OpenAI expanded its cybersecurity platform Daybreak with GPT-5.5-Cyber (85.6% CyberGym), Codex Security, and "Patch the Planet" — a funded initiative to actually fix vulnerabilities in open-source infrastructure (cURL, Python, Go, Sigstore) via Trail of Bits partnership. This represents a strategic shift from AI as a vulnerability-finder to AI as a vulnerability-fixer at scale. Simultaneously, the Latent Space episode on Gray Swan (aired same day) covers the red-teaming and AI security landscape from the defensive side — the two together give a comprehensive picture of where AI-security as a market is heading in mid-2026.

**3. Gray Swan / Latent Space: Prompt Injection and Agent Security Architecture (June 22)**
Zico Kolter (OpenAI board, CMU) and Matt Fredrikson (Gray Swan CEO) cover the emerging discipline of AI agent security — including the "lethal trifecta" framework for prompt injection risk (untrusted data + private info + exfiltration = exploitable), why current agents inherit user permissions ("a disaster"), and how automated red-teaming (their Shade product) beats human red-teamers. Key for founders building agentic products: security architecture for AI agents is now a real engineering discipline requiring dedicated tooling, not a general software security afterthought.
