# #09 — Dogfooding Is the Only Real Test for a Public API

## One-Line Summary

Anthropic dogfoods Claude Code with 2,500 internal users before shipping. OpenAI's help.openai.com runs on AgentKit. The Anthropic Founder Playbook has a full chapter on dogfooding.

## Supporting Evidence (Independent Sources)

Dario Amodei on Dwarkesh / OpenAI DevDay 2025 on Latent Space / Anthropic Founder Playbook MVP+Launch chapters / Marc Benioff ("customer service from 9,000 → 5,000 people")

## Action Implication for Memories.ai

P0: Have Lucy Desktop / Lucy App switch from internal endpoints (luci-oc.memories.ai) to the public API (mavi-backend.memories.ai). Move all internal customer-support + sales-support workflows to Claude agents running on the public API. If our own people refuse to use it, external developers won't either.
