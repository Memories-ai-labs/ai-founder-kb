# AI Founder Knowledge Base

This is a queryable knowledge base of AI startup founder learnings.

**Structure**:
- `patterns/` — 15 cross-cutting patterns (start here for high-level insights)
- `by-topic/` — organized by strategy / hiring / product / fundraising / engineering-management
- `by-person/` — one file per founder (western/ + chinese/)
- `by-company/` — one file per company
- `by-source/` — one file per podcast/publication
- `frameworks/` — 20 canonical playbook documents
- `sources-catalog/` — where to subscribe
- `memories-ai-actions/` — Memories.ai-specific action items

**Usage**:
- For "what does X think about Y": check `by-person/<X>.md`
- For "what are best practices for Z": check `by-topic/<Z>.md`
- For "what does the AI industry agree on": check `patterns/`
- For "what should I read first": check `frameworks/README.md` and `sources-catalog/README.md`
